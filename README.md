# 🥁 Drum Kit

A simple and interactive **Drum Kit** built using **HTML, CSS, and JavaScript**. Users can play different drum sounds by pressing specific keys or clicking the drum buttons on screen.

## 🎵 Features

- Click or press keys to play drum sounds  
- Visual feedback when a drum is played  
- Responsive layout and engaging UI  
- Smooth animations and sound effects
